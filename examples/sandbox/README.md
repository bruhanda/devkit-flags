# `@devkit/flags` — StackBlitz sandboxes

One subdirectory per example. Each is a standalone `package.json` + `index.ts` that StackBlitz can boot directly from GitHub.

Run any of them locally:

```bash
cd examples/sandbox/<name>
npm install
npm start
```
